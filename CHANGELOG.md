# Changelog

All notable changes to the Codryn Rule Graph Specification repository will be documented in this file.

The format follows Keep a Changelog principles and the specification uses Semantic Versioning.

## [0.2.0] - 2026-08-05

### Added

- executable reference slice for the Example RPG profile
- explainable requirement evaluation and deterministic runtime graph generation
- conformance suite coverage for valid and invalid reference datasets
- CLI commands for validation, bundle output, graph generation, and target evaluation

### Changed

- promoted versioned schema, profile, bundle, test, and documentation references from 0.1 to 0.2
- aligned local pre-push checks and repository validation workflows with the current CI surfaces

## [0.1.0] - 2026-08-05

### Initial Release

- initial repository structure for CRGS
- version 0.1 specification and architecture documents
- JSON Schema Draft 2020-12 foundation
- example profile and reference bundles
- placeholder workspace packages
- CI, linting, formatting, and validation scaffolding
