# Identifiers

The profile uses these identifier families.

- `pf1e.feat.*` for feats
- `pf1e.class.*` for classes
- `pf1e.skill.*` for skills
- `pf1e.source.*` for source anchors

Parameterized feat entities append the selected value to the family identifier, for example:

- `pf1e.feat.weapon-focus.longsword`
- `pf1e.feat.spell-focus.evocation`
- `pf1e.feat.greater-spell-focus.evocation`
