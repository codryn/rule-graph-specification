# Code of Conduct

The Codryn Rule Graph Specification project is intended to be a durable public standard. Contributors are expected to behave accordingly.

## Expectations

- Be precise, respectful, and technically honest.
- Critique proposals, not people.
- Distinguish normative requirements from exploratory ideas.
- Avoid inflammatory, dismissive, or exclusionary language.
- Respect the boundary between open specification work and copyrighted game content.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory conduct.
- Repeated bad-faith argumentation or deliberate misrepresentation.
- Posting copyrighted game text or proprietary assets without authorization.
- Disruptive behavior that materially impedes specification work.

## Enforcement

Maintainers may edit, remove, or reject contributions that conflict with this code of conduct or the project scope. Repeated or severe violations may result in temporary or permanent exclusion from project spaces.

## Reporting

Report conduct issues privately through the security contact process described in [SECURITY.md](SECURITY.md).
